Kết nối mTLS tới cổng API

Hướng dẫn cấu hình chứng thư máy khách để gọi API qua kênh mTLS.

1. Chuẩn bị chứng thư

Tạo khóa riêng và yêu cầu ký chứng thư (CSR). Không gửi khóa riêng qua thư điện tử.

openssl req -new -newkey rsa:3072 -nodes -keyout client.key -out client.csr

2. Gọi thử

Dùng curl --cert client.pem --key client.key tới địa chỉ sandbox.
