Luồng liên quan

Cung cấp tra cứu đồng bộ theo số định danh cá nhân. Dữ liệu trả về đã che theo quyền (PH-09). SLA cam kết P99 ≤ 3s, sẵn sàng 99,5%.

Đặc tả OpenAPI 3.1 (rút gọn)
openapi: "3.1.0"
info:
  title: Tra cứu thông tin công dân
  version: "2.1.0"
  description: Tra cứu CSDLQG Dân cư qua trục LGSP
paths:
  /api/v1/cong-dan/{soDinhDanh}:
    get:
      operationId: traCuuCongDan
      parameters:
        - name: soDinhDanh
          in: path
          required: true
          schema: { type: string, pattern: "^[0-9]{12}$" }
      responses:
        "200":
          description: Thông tin công dân (đã che theo quyền)
          content:
            application/json:
              schema:
                $ref: "#/components/schemas/CongDan"
        "404":
          description: Không tìm thấy
