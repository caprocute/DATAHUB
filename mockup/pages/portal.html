Hướng dẫn tích hợp NDXP

Tài liệu mô tả luồng kết nối hệ thống đơn vị với trục NDXP qua LGSP: đăng ký client, lấy token, gọi API và xử lý lỗi.

1. Chuẩn bị

  • Hoàn tất kết nạp HTTT (PH-01) và được cấp credential
  • Đăng ký sử dụng dịch vụ trên catalog (PH-02)
  • Cấu hình TLS 1.2+ và trust store nội bộ

2. Lấy access token

curl -X POST https://iam.lgsp.tinh.gov.vn/realms/lgsp/protocol/openid-connect/token \
  -d "grant_type=client_credentials" \
  -d "client_id=CONG-DVC" \
  -d "client_secret=***"
